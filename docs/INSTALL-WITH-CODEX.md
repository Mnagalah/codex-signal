# Install through Codex

Give Codex this repository URL and ask: “Install Codex Signal and finish its first setup.” It should use the package's installation/setup instructions and verify the actual plugin entry and menu bar before reporting completion.

The target is an Apple Silicon Mac with macOS 14+ and Codex desktop. Python 3.10+ is required; obtain permission for missing runtime installation. Keep the same desktop profile and existing Signal identity. Preserve all numbering/settings/acknowledgements and running chats. Installation does not require restarting Codex or weakening system security.
